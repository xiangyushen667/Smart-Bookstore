# Smart-Bookstore
智慧书城图书商城：基于 Vue 3 + Element Plus 的图书商城单页应用，支持分类筛选、关键词搜索、购物车与登录；以 Pinia 管理状态、localStorage 持久化，用 Vite 构建交付。  Smart Bookstore: a Vue 3 + Element Plus single-page book mall with category filtering, keyword search, cart and login; Pinia state management, localStorage persistence and a Vite production build.
